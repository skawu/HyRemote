---
name: 超过 1 分钟无输出的步骤视为卡死
description: 交互/测试命令超过 1 分钟没有输出就必须终止并重设计，不能继续等待
type: feedback
---

任何步骤或命令超过 1 分钟没有输出，一律视为卡死：立即终止该进程/命令，不再继续等待，并改用有界、可观测、会持续输出进度的方案。

**Why:** 用户明确要求把“超过 1 分钟无输出”当作卡死；此前的 slow-viewer 测试长时间无输出并被挂起，浪费了时间且没有形成证据。

**How to apply:** 长测试必须加超时和进度输出；禁止无界 `Start-Sleep`/后台静默等待；1 分钟内无输出就停止、清理并报告，不把卡死当成仍在运行。CI 等待使用 `gh pr checks --watch`/`gh run watch`，避免固定长 sleep。
