# English

`V0.2.0.0` is the **First User Trial** release of HyRemote: one Core, one shared runtime and four **peer** integration technologies, on the **Windows x86_64** and **Ubuntu-Linux x86_64** reference platforms.

This document records what this **released** version claims. It does not create a tag, a GitHub Release or a published artifact, and it carries no checksum of its own - the tag, the GitHub Release and the published artifacts are separate release actions.


## Release identity

- Release branch: `release/v0.2.0.0`
- Final tag: `v0.2.0.0`
- This document does not reference its own commit SHA: the final release commit/tag identity and the artifacts' `SHA256SUMS` are **release-time facts**, published with the artifacts after the tag.

## What this release is for

A real user can open a Qt Widgets or Qt Quick application on **one machine on a local network** and let a maintained VNC viewer on **another machine on the same network** connect to it, see the screen and control it - and every fact the user is told about authentication, encryption, remote input and the listener matches the behaviour actually shipped, one by one.

## Four peer integration technologies

The four integration technologies are **peers**, with no primary/preview hierarchy:

- **Embedded C++ API** - `HyRemote::RemoteAccess`, the single application-facing object, with an explicit `start()` / `stop()`;
- **Declarative QML API** - `import HyRemote`;
- **Generic Plugin** - an ordinary Qt application activated with `-plugin hyremote`, with no HyRemote headers, API calls or link dependency in the application itself;
- **Transparent QPA** - the `-platform hyremote` platform-plugin route.

## Listener address

- The default is `0.0.0.0:5921`: **reachable on every IPv4 interface of the host**. That is deliberate product behaviour, not accidental widening.
- It can be narrowed to **one exact local IPv4** (`setListenAddress`);
- It can be narrowed to **one named interface** (`setListenInterface`), where the runtime resolves that interface's current single IPv4 and follows it as it changes;
- There is no silent address substitution: an interface that cannot be resolved, has no IPv4, or is ambiguous fails by type with the reason, and never falls back to the wildcard, to loopback or to another interface.

## Security boundary

| Fact | V0.2.0.0 |
| --- | --- |
| Authentication default | **off** |
| Authentication profile | **none** |
| Transport encryption default | **off** |
| Transport encryption profile | **none** |
| Remote input default | **off**, and must be enabled explicitly |
| Correctness transport security type | RFB `SecurityType None` |

- An unauthenticated, unencrypted deployment is for a **trusted local network** and is **not Internet-safe**: that is this release's **truthful** security boundary, and it makes no "Internet-safe" claim.
- Stronger profiles **fail closed**: `AuthenticatedEncrypted` fails with `SecurityUnavailable` before any listener is created and does not fall back to a weaker profile; a real encrypted transport is not part of this release.
- The transport-security capability is optional at build time, and enabling it **only** makes stronger profiles configurable - it does not change any default above, nor the default profile.
- No password or key material reaches a log, an event or a getter.

## Known limitations

- no native TLS or VeNCrypt transport - the real encrypted backend is not part of this release;
- no Session Registry and no multi-session operations;
- **no Qt 5 qualification**: Qt 5.15 LTS, Embedded Linux, ARM64 and further QPA private-ABI combinations are outside this support statement;
- no ZRLE or damage-region encoding - the correctness baseline is RFB 3.8 Raw;
- remote input is limited to the documented normalized input model; composition/IME pre-edit is outside the contract;
- Real, measured input facts: **pointer, buttons and wheel** work; the **bounded logical-key** path works; **printable text works** - in the real LAN trial the maintained VNC viewer on the second machine entered Latin characters, digits and Chinese text; full IME/pre-edit/composition parity is **not claimed**;
- Remote control is **application-scoped**: if the host locally activates another application or the desktop, the remote pointer does **not** reliably reclaim OS activation for the target application; reactivate the target application locally if necessary;
- Correctness first: remote interaction may show **noticeable latency** compared with local input (operator feedback: noticeable but usable). This version makes no performance promise.
- complete branding and the 01-09 learning curriculum belong to a later train.

The living, per-topic version of these boundaries is [`docs/known-limitations.md`](../known-limitations.md); the exact current matrix is [`docs/compatibility.md`](../compatibility.md).

## Stop, disable and rollback

- `stop()` is the **absolute cancellation boundary**: the intent and the interface follow are cleared immediately, the listener goes with them, and nothing restarts afterwards;
- QML `enabled=false` and the equivalent disable paths in Generic and QPA go through the same runtime semantics;
- Rollback is **reinstalling the last accepted artifact**: the tree is self-contained (`build/install` or an archive of that tree), depends on no build tree and no Qt SDK path, so replacing the directory is the whole procedure;
- A user never has to rebuild on their own machine to return to the previous version.

## Artifact and checksum publication contract

- The handoff artifact may only come from the install root produced by `build.cmd install` - `build/install` - or from an archive of **that exact tree**; developer intermediate output such as `build/examples/**` must never be handed to a user;
- The tree carries its own `HYREMOTE-MANIFEST.txt`, which records authentication, encryption, remote input, the default listener and the transport-security **build capability** as separate facts;
- The published source archives and their `SHA256SUMS` are produced from the accepted tag afterwards and published alongside this document; **this document carries no checksum**.
