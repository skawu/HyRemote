# Installed SDK Consumption

This guide describes the prebuilt/installed-prefix path. It is intentionally separate from source `add_subdirectory()` consumption.

## Contract

A HyRemote install prefix contains public headers/libraries, CMake package metadata, the Apache-2.0 license, and product runtime payload owned by HyRemote packaging. Normal application code links `HyRemote::RemoteAccess`; it does not discover or link internal Core/transport targets individually.

Point CMake at the HyRemote prefix:

```bash
cmake -S . -B build \
  -DCMAKE_PREFIX_PATH="/path/to/Qt/6.8.3;/path/to/HyRemote"
```

Then consume the package:

```cmake
find_package(Qt6 6.8 REQUIRED COMPONENTS Widgets)
find_package(HyRemote CONFIG REQUIRED)

target_link_libraries(MyApp PRIVATE Qt6::Widgets HyRemote::RemoteAccess)
```

For Quick, request the application's normal Qt Quick components and keep the same HyRemote product target.

## What `find_package(HyRemote)` means

`HyRemoteConfig.cmake` resolves the dependencies required by the built SDK and loads exported `HyRemote::` targets plus `hyremote_deploy()`. It is generated by the HyRemote install/export rules; it is not expected to exist merely because a source directory was added to another project.

## Install from a HyRemote source checkout

A developer may create an SDK prefix from source:

```bash
cmake -S . -B build-hyremote -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_PREFIX_PATH=/path/to/Qt/6.8.3/<toolchain> \
  -DCMAKE_INSTALL_PREFIX=/path/to/hyremote-sdk
cmake --build build-hyremote --parallel
cmake --install build-hyremote
```

That resulting prefix is then consumed with `find_package(HyRemote CONFIG REQUIRED)` as above.

## Deployment

After the application target exists, call the installed helper where appropriate:

```cmake
hyremote_deploy(TARGET MyApp)
```

See `docs/deployment.md` for the current responsibility boundary.

## Validation fixture

`tests/consumer-installed-sdk` is the repository's clean installed-prefix consumer. It must continue to build without repository-private include paths or knowledge of backend types.
