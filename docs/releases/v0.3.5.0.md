## Security boundary

- 默认 `0.0.0.0:5921`、远程输入关闭；默认 RFB `Insecure` **没有认证、没有传输加密**。仅用于可信网络；不可公网直连。
- 可选传统 VNC 认证仍不加密图像、键盘或会话；`AuthenticatedEncrypted` 未实现，必须失败关闭，不自动降级。

Composite remote frames without changing the local application's pixels; refuse remote output if an enabled watermark cannot be honored.
- **Durability (#754):** atomic state-file replacement, bounded reads and observable redacted errors for failed explicit writes/removals.
- **Development governance (#755/#756):** Qt-free governance for vetted prose-only changes and canonical fail-closed positive test selection; neither replaces final release testing.
