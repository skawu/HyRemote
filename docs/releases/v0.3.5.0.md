## Product outcome

- **Host configuration and persistent state (#591):** common configuration, writable state and protected secret-reference selection rules across applicable integration routes using the shared Runtime; no database consumer.
- **Server-side static text watermark (#589):** explicitly enabled nonempty UTF-8 text, off by default; enabled defaults are one bottom-right line and opacity 0.35; tiling is opt-in. Remote-frame composition leaves local host pixels unchanged; refuse remote output when the enabled mark cannot be honored.
- **Persistent-policy reliability (#754, #812, #1047):** atomic writes, bounded reads, redacted diagnostics and fail-closed remote startup for failed explicit persistence or corrupted restoration. Invalid stored opacity/font-size no longer silently fall back to defaults.
- **Development test efficiency (#755, #756):** Qt-free checks for vetted documentation and fail-closed positive test selection through `build.cmd --test-filter=REGEX`; not a substitute for full release qualification.
