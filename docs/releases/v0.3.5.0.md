## 本版用户成果

- **可运维宿主配置与持久化路径**（#591）：适用的四种前端通过共享 Runtime 正确选择配置、状态及 secret 引用。Windows 原生 Unicode 环境变量支持真实中文目录；无效配置/状态路径失败关闭，不静默写入乱码目录。
- **服务端远端文字水印**（#589）：默认关闭；显式非空文本启用，默认右下角单行、透明度 0.35，可选择平铺。只合成远程 framebuffer，不污染宿主本地图像；启用后无法合成时停止远程输出，不退回无水印帧。
- **持久化与明确关闭**（#754、#777）：策略保存/删除原子且有界；Generic 使用 `watermark-state=off`、QPA 使用 `hyremote-watermark-state=off` 明确清除持久水印，重启仍关闭；仅传位置等修饰参数但无文本会被拒绝且保留原有策略。
- **QML 与边界修复**（#784）：新 QML 实例**省略**水印属性可恢复已有持久策略，显式 `watermarkText: ""` 或启动前程序化空文本则清除策略并持续关闭；Running 期间被拒绝的文本/角落修改不得污染 getter 或后续重启；角落文字的排版边距与真实字形墨迹边界均须完整容纳，否则 `does not fit` 并失败关闭，不截断操作员文字。
- **Windows 启动参数/QPA 正确性**（#761、#774、#775）：中文及空格水印文本保留原码点；Qt6.8.3 显式 QPA `delegate=windows` 实际启用远程服务；Unicode 配置、状态和 secret 选择器按预期路径工作。
- **工程测试维护**（#755、#756）：CI 治理及可定向测试改进不代替版本候选的完整验收，也不是新的远程产品能力。

## Product outcomes

- **Operable host paths (#591):** consistent configuration, writable state directory and secret-reference choices in the shared Runtime across applicable integration routes. Native Windows Unicode paths preserve Chinese directory names; invalid choices fail closed without creating mojibake siblings.
- **Server-side static text watermark (#589):** disabled by default; explicitly enabled nonempty UTF-8 text, default bottom-right at opacity 0.35, tiling opt-in. Only remote frames are decorated. When enabled compositing fails, no undecorated frame may silently escape.
- **Durable and explicit OFF (#754/#777):** bounded atomic policy persistence. Generic `watermark-state=off` and QPA `hyremote-watermark-state=off` explicitly remove a stored mark, remaining off across restart; modifier-only launch without text is refused without deleting stored policy.
- **QML and watermark bounds (#784):** omission intentionally restores an existing saved policy, while an explicitly empty QML assignment or pre-start setter clears it. Running-phase edits rejected by Runtime must not corrupt QML getters or prevent a later valid restart. Corner placement must reserve margins and actual glyph ink; an overlarge mark is rejected fail-closed instead of being clipped.
- **Unicode argv and QPA delegate (#761/#774/#775):** Windows zero-code CJK marks, including spaces, preserve code points; explicit `delegate=windows` really arms the Qt6.8.3 remote service.
- **Maintainer tooling (#755/#756):** CI governance and focused tests are not new user-facing remote-access capabilities or substitutes for whole-candidate evidence.

## Security boundary

- Default `0.0.0.0:5921` RFB service with remote input disabled. Default `Insecure` has **no authentication or transport encryption** and is for trusted LANs only, not the public Internet. Legacy VNC authentication also leaves session traffic unencrypted. `AuthenticatedEncrypted` is not implemented and must fail closed.
- Actual qualification is Windows Qt6.8.3 for four routes, and bounded Qt5.15.2 C++/Widgets only; **no** automatic Qt5 QML/Generic/QPA/Quick, Linux/ARM64/RK3588/EGLFS/Wayland Supported claim.
- Host fonts affect watermark glyphs. No logo/image watermark, Docker, TLS, Qt6.5/6.12 or V0.4 feature expansion. Field reports #565/#567 are not claimed fixed without separate evidence.
- Source-only publication is planned. No binary installer, signed payload or checksum assets are claimed. Qt/third-party redistribution licenses must be checked against what is actually distributed.
- Candidate acceptance does **not** assert that protected `main` promotion, annotated tag, GitHub Release, tag audit or audited backmerge have happened.
