## 用户能力和缺陷修复

- **宿主配置及持久状态（#591/#793）：** 四种适用接入方式 C++/QML/Generic/QPA 复用唯一 Shared Runtime 的 config/state/secret 引用及路径优先级。显式无效路径拒绝相关能力，不静默回退其它状态目录；描述符变化时旧目录隐式恢复缓存失效；未实现数据库消费者或 Docker 正式资格。
- **服务器端静态文字水印（#589/#754/#777/#784）：** 默认关闭，显式启用 UTF-8 文字，默认右下角单行/不透明度 0.35，可选平铺。只修改远端 RFB 帧，不更改宿主 Qt 窗口本地像素；持久策略原子写入、有界读取，文本过大、状态损坏或写入失败必须拒绝远端输出，绝不退化为无水印帧。显式 OFF、空值和未指定值有区别。
- **Unicode/QPA 与安装环境（#761/#774/#775/#800）：** 正确处理中文、空格与路径，QPA `delegate=windows` 仅在精确 Qt 6.8.3 私有 ABI 范围；先安装再测试时不再受已安装 Qt DLL/插件路径污染。
- **自动复合输出 DPR 修复（#806/#807）：** Generic/QPA 的逻辑像素画布输出 DPR 为 1.0，不再错误沿用子画面 DPR=2.0；已有混合子帧 DPR 1/2 的自动化像素几何回归。**真实系统 200% 物理测试未执行**。
- **静态画面与内存生命周期（#789/#797、#790/#798）：** 有界空闲采集探测；零 Viewer 时符合条件可释放原始帧缓存，重连保留可用性。**未测量** RC7 Host CPU、RSS 或 FPS 改善，不宣称 RK3588 实机问题已解决。
- **测试可靠性（#755/#756/#799/#800）：** 正数用例选择防零测试假阳性，全幅 Raw/TRLE 传输回归和安装后测试环境修复；不属于新增支持平台或公网安全能力。

## Security boundary

- 默认 `0.0.0.0:5921` 监听，远程输入默认关闭；默认 RFB `Insecure` **无认证、无传输加密**，只可用于可信局域网，**不可直接暴露公网**。传统 VNC Auth 也不加密画面、输入或会话。
- 未实现的 `AuthenticatedEncrypted` 必须失败关闭、不得自动降级；无原生 TLS、Gateway 或公网安全服务承诺。
- 本版计划只发布**源码 GitHub Release**。经受保护发行分支并入 main、复核 main 精确 HEAD 后才能创建附注式 `v0.3.5.0` 标签；当前不宣称二进制包、签名、校验和附件或已完成回合并。再分发许可证以实际制品为准。

## Security boundary

- Default RFB `Insecure` listener at `0.0.0.0:5921` has **no authentication and no transport encryption**; remote input is off by default. Use only on trusted LANs, **never expose directly to the Internet**. Legacy VNC Auth encrypts neither pixels nor input/session.
- Unsupported `AuthenticatedEncrypted` must fail closed without downgrade. No native TLS, Gateway, identity service or Internet-safe access is promised.
- A **source-only GitHub Release** is planned. The annotated `v0.3.5.0` tag must target the exact reviewed **main merge HEAD** after protected release→main promotion; binary installers/signatures/checksums are not qualified, and audited backmerge is not yet done. Check Qt/third-party licensing for any actual redistributed payload.
