### 用户可用能力与修复

- #591：共享 Runtime 的配置、状态与 secret 引用路径优先级；四种适用接入方式采用一致的宿主路径契约，不承诺未实现的数据库消费者。
- #589/#754/#784/#793：服务端静态 UTF-8 文字水印（默认关闭，显式启用、右下角单行或显式平铺），持久策略原子写入、错误失败关闭；修复 QML 显式空值/省略差异、Running 期间拒绝变更、角落边界以及配置描述符切换时的缓存身份失效。水印仅叠加到远端帧，不改宿主本地像素。
- #797：基于 RFB 实际 served-pixel 反馈的静态 Quick 抓帧门控，保留有界 100ms 探测与输入/变化唤醒；#798：无 Viewer 时释放 Shared Runtime 实际 raw latest frame storage，保持 standalone RFB bootstrap 与重连首帧/水印安全；#799：单 FBU、单整帧矩形 Raw/TRLE wire 回归及可选 1920×1080 测试 profile；#800：修复 install 后测试 PATH 对 Qt 插件发现的干扰。这些不代表 RK3588 现场性能改善已实测。

### 安全、兼容性与限制

- 默认 `0.0.0.0:5921` 的 RFB `Insecure` **无认证、无加密**，仅用于可信局域网；远程输入默认关闭。传统 VNC Auth 不加密图像或输入；`AuthenticatedEncrypted` 未实现且必须失败关闭，不能公网直连。
- 仅 Windows x64 Qt 6.8.3 四接入方式和 Qt 5.15.2 已有有界 C++/Widgets 单元获得上述候选资格。**未验证**第二台物理机、完整四路线示例集、Qt5 QML、Linux/ARM64/RK3588/Buildroot/EGLFS、GPU、TLS、Docker、全链路 FPS/CPU/RSS。
- #567 大页面条带刷新原因仍未证实；#789 RK3588 静态 Viewer CPU 117.2%、#790 断连后 RSS/PSS 高水位（未证实增长型泄漏）、#791 EGLFS 双实例 DRM/平台看护问题均保持独立追踪。目标 RK3588 结论为 `TARGET_NOT_RUN`，不得把 Windows 结果当作目标板修复验收。#609 CPU/RSS/FPS 独立 P1 测量并行进行。
- #749 1080p 水印合成微基准仅测合成，不含抓帧、编码、传输。没有二进制安装包、签名、校验和附件的发布承诺。Qt/第三方再分发许可证须按实际载荷核查。

### Delivered functionality

- #591 shared Runtime host configuration/state/secret-reference path precedence across applicable integration routes; no database consumer is shipped.
- #589/#754/#784/#793 explicit server-side UTF-8 text watermark, off by default, with persistent atomic state, fail-closed error handling, QML omitted-versus-empty semantics, Running-change rejection, corner fit and descriptor-path cache invalidation. Watermark is applied to remote frames only.
- #797 static Quick capture demand gating using real RFB served-pixel feedback with bounded 100ms probing and wakeup; #798 zero-viewer raw latest-frame storage release while preserving standalone RFB bootstrap and safe first frame on reconnect; #799 single-FBU/single-full-frame-rectangle Raw/TRLE wire tests and optional 1080p test profile; #800 installed-prefix PATH/plugin test isolation. These are not claims of measured RK3588 improvement.

### Security and scope boundaries

- Default `0.0.0.0:5921` RFB `Insecure` has **no authentication or encryption**, intended for trusted LAN only; remote input defaults off. Legacy VNC Auth does not encrypt video or input. `AuthenticatedEncrypted` is unavailable and must fail closed; no Internet-facing safety claim.
- Qualified candidate cells are Windows x64 Qt 6.8.3 four routes and bounded existing Qt 5.15.2 C++/Widgets. **NOT_RUN:** second physical machine, full four-route example campaign, Qt5 QML, Linux/ARM64/RK3588/Buildroot/EGLFS, GPU, TLS, Docker and end-to-end FPS/CPU/RSS.
- #567 large-page stripe refresh remains undiagnosed; #789 RK3588 117.2% static-viewer CPU, #790 disconnected RSS/PSS high-water (not proven growing leak) and #791 EGLFS DRM/supervisor dual-instance conflict remain tracked independently. RK3588 target acceptance is `TARGET_NOT_RUN`. #609 performance measurement remains an independent P1 track.
- #749 compositor-only 1080p watermark timings are not end-to-end performance. No binary installers, signatures or checksums are claimed. Redistributed Qt/third-party licenses require payload-specific review.
