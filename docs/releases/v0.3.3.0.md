# HyRemote V0.3.3.0

- Release branch: `release/v0.3.3.0`
- Release code SHA: `de94a0a` (release branch adds only the version bump)
- Reference platform: **Windows x86_64, Qt 6.8.3**
- Linux desktop, ARM64/EGLFS and Wayland remain user-validation targets, not release gates.

## What this release adds

- RFB Raw fallback plus TRLE when the viewer advertises it, with 64x64 damage tiles and bounded
  bounded per-viewer unsent damage.
- Incremental and non-incremental framebuffer requests, resize/full-refresh handling and
  per-viewer isolation.
- Demand-driven capture with 60 FPS pacing, so a connected idle viewer no longer spins the GUI.
- Two maintained Windows viewers: RealVNC Viewer 7.15.1 and TightVNC 2.8.85.
- Optional traditional RFB VNC password authentication (VncAuth), with correct-password accept and
  wrong-password reject tested on both viewers. This is authentication, not transport encryption.

## Security boundary

- Default listener is `0.0.0.0:5921`; remote input is disabled by default.
- Default authentication is **off** and the RFB transport is **unencrypted**.
- Optional traditional RFB VncAuth is available only in a build configured with transport security;
  it authenticates the viewer but does not encrypt the stream.
- Deploy only on a trusted network unless the deployment adds its own encryption and access control.
- TLS/VeNCrypt, cloud relay and the full management plane are not part of this release.

## Known limitations

- TightVNC does not advertise TRLE and therefore uses Raw with materially higher bandwidth. RealVNC
  is the TRLE-qualified viewer in this release.
- Visual cursor shape is not exposed by either maintained viewer in the tested configuration; this
  is accepted as a viewer-local limitation. Pointer position, buttons, wheel and remote input are
  qualified separately, and the cursor pseudo-encoding wire tests pass.
- VNC authentication is optional and unencrypted; it is not TLS/VeNCrypt.
- Linux desktop, ARM64/EGLFS, Wayland, Qt 5.15/6.5 and arbitrary third-party viewers are not
  claimed by this release.
- TLS, cloud relay, full management plane and hardware video encoding remain out of scope.
