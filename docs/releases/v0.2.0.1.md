# 中文

## 发布身份

- 版本：`v0.2.0.1`
- 发布分支：`release/v0.2.0.1`
- 谱系：`V0.2.0.0`（First User Trial）的有界维护修复，继承其已验收历史
- 验收平台与工具链：Ubuntu 24.04 x86_64 + Qt 6.8.3，Windows x86_64 + Qt 6.8.3

`v0.2.0.1` 是 `V0.2.0.0` 的有界维护 hotfix。它不增加新功能，也不改变已发布的用户承诺，只修复构建、安装、部署与可运行示例这条链路上被本次维护直接涉及的缺陷。

## 这次发布修了什么

- Linux：same-SONAME 的 Qt 运行库选择（部署树的可运行性）
- POSIX：Qt 发现，以及存在多个 6.8.3 kit 时 fail-closed 而不是猜测
- Generic / QML：部署后 payload 的可重定位
- installed `qml-basic`：不再依赖 build tree 的 QML import root

Windows 上已经验证过的行为保持不变。

## 监听地址

默认监听 `0.0.0.0:5921`，即主机的 IPv4 接口，而不是仅 loopback。

## 安全边界

- 认证：OFF（profile `none`）
- 传输加密：未加密（profile `none`）
- 远程输入：默认 OFF
- RFB 正确性路径为 `SecurityType None`

因此本版本只适合 trusted LAN，不适合暴露到 Internet。要限制可达范围，请显式设置监听地址或网络接口，并先阅读 `docs/security.md`。

## 制品与校验和发布合同

本次发布制品为 source（`tar.gz` 与 `zip`）、Windows install tree、Ubuntu install tree，以及覆盖这些文件的 `SHA256SUMS`。校验和与 tag、GitHub Release 一样属于独立的发布动作；本文件本身不创建这些对象，也不携带自身校验和。

## 已知限制

会话操作、示例产品化与 GUI 品牌化属于后续 train，不在本次有界维护之内。QML/输入法组合等既有已知限制与 `V0.2.0.0` 保持一致。

# English

## Release identity

- Version: `v0.2.0.1`
- Release branch: `release/v0.2.0.1`
- Lineage: a bounded maintenance repair of `V0.2.0.0` (First User Trial) that inherits its accepted history
- Qualified platforms and toolchains: Ubuntu 24.04 x86_64 + Qt 6.8.3, and Windows x86_64 + Qt 6.8.3

`v0.2.0.1` is a bounded maintenance hotfix on top of `V0.2.0.0`. It adds no new capability and changes no published user
promise; it repairs only the build, install, deploy and runnable-example path that this maintenance touches.

## What this release fixes

- Linux: same-SONAME Qt runtime selection (deployed-tree runnability)
- POSIX: Qt discovery, and fail-closed behaviour instead of guessing when several 6.8.3 kits are present
- Generic / QML: relocatable deployed payload
- installed `qml-basic`: it no longer depends on a build-tree QML import root

Behaviour already verified on Windows is unchanged.

## Listener address

The default listener is `0.0.0.0:5921` - the host's IPv4 interfaces, not loopback only.

## Security boundary

- Authentication: OFF (profile `none`) - the endpoint performs no authentication at all
- Transport encryption: unencrypted (profile `none`), so the stream is not encrypted
- Remote input: OFF by default
- The RFB correctness path is `SecurityType None`

It is therefore for a trusted LAN only, and it is not Internet-safe. To narrow reachability, set the listen address or
network interface explicitly, and read `docs/security.md` first.

## Artifact and checksum publication contract

The published artifacts are the source archives (`tar.gz` and `zip`), the Windows install tree, the Ubuntu install tree,
and a `SHA256SUMS` file covering them. The checksums, like the tag and the GitHub Release, are separate release actions;
this document does not create them and carries no checksum of its own.

## Known limitations

Session operations, example productization and GUI branding belong to later trains and are outside this bounded
maintenance. The pre-existing known limitations (for example IME/pre-edit composition parity) are unchanged from
`V0.2.0.0`.
