## 本版修复

- 显示一致性（#567）：同帧损伤区域与编码、已呈现像素比较；隐藏全部组合画面时清除旧像素并保持最后有效尺寸。
- CPU 路径（#789）：静态/空闲采集需求、socket 背压反馈、diff 复用、tile 比较跳过与 TRLE 有界分配。
- 资源生命周期（#790）：零 Viewer 时释放空闲像素缓存、取消 timer、组合采集所有权及排空、水印跳过。
- 远程鼠标：按每个 Viewer 已通告的 framebuffer 尺寸解析坐标，避免握手后首帧前的输入丢失及尺寸不一致。

## Maintenance fixes

- Display consistency (#567): same-frame damage and encoding, presented-pixel comparison; clear stale composite pixels when all sources are hidden while preserving the last valid size.
- CPU path (#789): static/idle capture demand, socket backpressure feedback, diff reuse, tile comparison skipping and bounded TRLE allocation.
- Resource lifecycle (#790): zero-viewer idle pixel cache release, timer cancellation, composite ownership and drain, watermark skipping.
- Remote pointer: use the framebuffer size already advertised to each Viewer to avoid input loss before the first frame and coordinate mismatch during resize.

No new feature, default-enabled experimental native capture, or change to the four foundational integration routes.
