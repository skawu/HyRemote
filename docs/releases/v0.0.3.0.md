# HyRemote v0.0.3.0 — Transparent QPA milestone release notes

Status: **candidate / acceptance pending**

`v0.0.3.0` is the Windows x86_64 + Linux x86_64 Transparent QPA Proxy product milestone. While the status marker above is present, this file is candidate material rather than a release claim. The milestone adds no/minimal-source-change remote access while preserving the qualified native Qt platform path and reusing the same shared HyRemote runtime.

## Product scope

An existing Qt application remains Qt-only at link level. Deployment is:

```cmake
find_package(HyRemote CONFIG REQUIRED)
hyremote_deploy(TARGET MyApp QPA)
```

and launch is:

```text
MyApp -platform hyremote
```

The installed SDK deploys `qhyremote` as a package-owned Qt platform MODULE plus the same shared `HyRemoteRemoteAccess` runtime. It does not export `HyRemote::QpaPlatform` as an application CMake target.

The V0.0.3.0 QPA package is exact-private-ABI qualified for Qt 6.8.3. The default launch remains view-only; explicit control uses `hyremote-input=true`. Local native display/input remains authoritative and remote access is additive.

## Security boundary

The shared RFB correctness transport still uses **SecurityType None**. QPA does not add authentication or encryption. Loopback is the default bind address and remote input is off unless explicitly enabled.

## Acceptance boundary

While the candidate status marker is present, #32 acceptance is still outstanding. Required evidence includes both reference operating systems and the physical native local-display/local-input + remote coexistence evidence tracked by #109. Hosted offscreen/Xvfb results cannot substitute for that evidence, and #109 must not be used to disguise #74 hosted-runner infrastructure failures.

After all #32 gates pass on `release/v0.0.3.0`, release finalization removes the candidate status line before the PR leaves Draft. The accepted branch then merges to `main`, receives annotated tag `v0.0.3.0` on the exact accepted main HEAD, and is reconciled through `backmerge/v0.0.3.0` to `develop`.
