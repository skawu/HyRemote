# HyRemoteTool SDK 开发与诊断工作台 — 产品需求与实施基线

> **2026-11-27 生效条件：Human [H-T01=B](https://github.com/skawu/HyRemote/issues/594#issuecomment-7214790385) 已裁决，本次受审范围同步合并后执行。** 以下现行设计替代后附的历史 D+A 远程工作台方案；历史证据仅用于兼容维护。正式访问/查看/操作交由独立客户端，不在 Tool 新造 Viewer。存量已发布基础访问保留至替代客户端真实交付、迁移指引与回退验收完成，退役日期另定。

## 1. 任务及首期交付
V0.3.6.0 S1 面向 Qt 开发者、SDK 集成人员、故障定位人员。主流程：选择 SDK 根与实际 Qt Kit → 核对版本/架构/构建信息/可见依赖与缺失项 → 选择 C++/QML/Generic/QPA → 阅读和复制已验证最小集成步骤 → 明确输入端点进行协议/帧观测 → 查看来源、错误及下一步 → 预览脱敏报告并显式复制/保存。不得扫描设备、自动改工程、上传数据或伪造远端事实。
S1 验收范围：#581 新研发工作台及 SDK/Kit 静态核对/准确指导；#585 现有诊断、协议状态/帧尺寸/计数/吞吐/实际失败分类及脱敏报告；#590 语言；#582/#583/#584 存量 RFB 兼容与安全回归，不扩展；#586 实际安装任务验收。S2 #587 深化宿主诊断导入及来源对照，S3 #588 深化实际 CMake 消费、Kit/ABI 与部署验证。性能对照与采集/编码/资源分析仅消费可核验 Host/Client 证据，未知标未知，下一版本按真实需求设计，不把客户端 FPS 当 Host 指标。

## 2. UI 设计
顶栏品牌、版本、语言/帮助；主导航：开发环境、集成指导、连接验证、诊断报告。首次启动开发环境；不存在或不合格以可操作说明呈现；仅展示已实现项。开发环境使用用户明确选择的 SDK/Kit 路径、逐项事实/方法/结果/下一步；静态检查不冒称 ABI 或运行合格。集成指导从仓库现有 SDK 安装文档及四接入可运行例程提取，按实际 Qt/平台限制展示，复制而非写入工程。连接验证从已有 RfbClient/诊断模型读取观察结果，显式连接与结束；显示真实接收帧尺寸、计数、状态，可用单帧预览辅助像素验证，非持续日常访问工作区。兼容入口继续提供既有基础 RFB、默认只读及显式控制；不得新增设备管理、全屏/缩放、多会话能力。诊断报告保留脱敏预览/显式复制保存，非已知数据标未知；不收集秘密、远端业务画面或输入正文。
视觉：统一系统字体/间距 8/12/16，完整双语文字、主次动作、可读状态/空态/错误；800×600 与 1366×768 逻辑客户区、系统字体放大、键盘焦点、可达操作。Qt6.8 独立 Tool 新研发界面优先 Qt Quick/QML + C++ models；先审构建、部署及 Qt5 已发布兼容路径，禁止为纯 UI 美化引入双 Viewer 或重写协议。保留 Qt5 现有合格兼容能力和 SDK Qt5/6 支持不变；技术基线变更须真实验证后受审，不依据本 PR 宣称迁移完成。

## 3. 工程与验收边界
复用既有 RfbClient、FramebufferView、ProfileStore、ToolDiagnosticSession/BasicDiagnostics、语言与 report builder；SDK 静态读取现有 manifest/CMake targets/Kit 元数据、明确来源和未知，不能把存在文件作为实际运行/ABI PASS；四接入指导依当前公开 API/可运行示例。先审可实施模型、Qt5/6 构建兼容及新增检查测试入口；不得边开发边临时定义验收。使用现有 Tool CTest/--verify-ui，在旧 oracle 基础上补实际布局/研发路径与最小读取负例；新增测试身份只有现有 seam 不可证明才事前确定。真实安装验收：选择已安装 SDK/Kit、识别缺项/不匹配、四路线步骤与实际示例相符、显式连接真宿主观察帧/故障、报告默认遮蔽且复制/保存有效，双语实际截图审查；存量已验证行为和必要安全回归保留。Qt5/Qt6 现行必需 CI、独立审查、exact candidate G6、安装证据不豁免。#1076 旧候选 HOLD，不能把旧 PASS 当新设计验收。
