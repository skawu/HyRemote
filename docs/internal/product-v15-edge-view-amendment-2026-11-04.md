# 《HyRemote 产品设计文档》V15 增量正文设计候选

> 归属：#827 · 基线：正式版 HYR-PD-001/V14（2026-11-03）。
>
> 本文件是拟并入 V15 的**产品规范正文**，不是独立发布功能说明；原 V14 已批准文字继续有效。仅对工厂边缘接入相关条款作增补，不删除既有 52 个二级要求。此稿供完整设计一致性审查，未经正式批准不替代 V14。

## 一、设计定位与产品承诺

HyRemote 面向已有 Qt 工业应用提供受控远程查看和操作。对拥有多个 HMI 且生产网络不能直接暴露公网的工厂，产品还应支持以下部署：HMI 内集成 HyRemote Framework；工厂一台能够访问 HMI 内网、同时能够访问经批准云端服务的 PC **只安装 HyRemoteView**；经客户管理员开启并限定共享目标后，工厂 HyRemoteView 向可选 HyRemote Gateway 建立主动安全连接；异地人员使用**相同 HyRemoteView 产品**，通过该 Gateway 申请访问允许的 HMI。用户不需要另装独立 Edge Connector、Support Bridge、VPN、任意代理或客户机后台伴生软件。

HyRemote Gateway 作为可选云端或自托管受管服务，不属于上述“工厂 PC 不额外部署软件”的限制对象；本地 Direct 是基础能力，没有 Gateway、企业账号或外网时仍应正常使用。

## 二、拟修订的已有条款

### 1.4 设计范围与非目标（增补）

远程访问可经直接网络路径或受管的工厂边缘接入路径实现。工厂边缘接入由 HyRemoteView 自身提供，不要求修改 HMI 中的原有业务程序，也不授予远端用户通向工厂全局网络的权限。远程应用访问不等于操作系统远控、站点 VPN 或任意网段 TCP 转发。

### 2.1 产品组件及其协作方式（扩写）

HyRemoteView 是统一客户端产品，根据管理员明确启用的配置承担以下角色：

- **本地远程客户端：** 在工厂网络中直接连接指定 HMI，完成身份核验、画面查看及受权控制。
- **工厂边缘接入：** 在同一 HyRemoteView 内管理经客户授权发布的 HMI 设备清单，保持受控出站接入，并只为获准的远程会话转发对应设备通信。
- **异地远程客户端：** 通过 Gateway 选择获授权站点及设备，建立受管会话，完成设备端最终认证和授权。

三种角色为同一产品能力，不分别部署为第二款程序。HyRemoteTool 仍只承担 SDK/环境诊断；Gateway 承担可选服务端路由、连接协调、认证与受管记录；HMI 设备端 Framework 始终拥有访问目标及输入的最终决定权。

### 2.2 共享运行时与两种远程访问协议（补充）

边缘接入不改变 HMI 端一套 Shared Runtime 和 Core 的事实。标准 RFB 与 HyRemote Native 继续作为独立设备协议存在，受管网络路径不应强制生成新的宿主采集/编码实例。HyRemoteView 和 Gateway 的站点身份或路由许可不等于设备端 ViewGrant 或 ControlGrant。第三方 VNC 客户端的 Direct/RFB 互通保持原有承诺；受管跨站点的第三方 RFB 兼容须按实际安全与版本能力单独声明，不能因存在 Gateway 就认定全部协议自动可经公网暴露。

### 5.3 直接连接、受管接入及恢复（扩写）

**Direct 模式：** 同网段或已具备可信路由的用户可使用 HyRemoteView 直接访问获准 HMI。不存在云端账号或 Gateway 的依赖。 

**Managed Edge 模式：** 客户管理员在工厂 HyRemoteView 中明确开启站点边缘接入、完成 Gateway 信任建立与设备清单授权；工厂端主动对外连接。异地 HyRemoteView 先获得对应站点/设备的受管准入，再通过工厂端受限路径连接到目标 HMI，最终仍由 HMI 校验身份、查看许可与控制许可。

两种模式的身份核验、权限及当前状态分别呈现。受管连接失败时，不得静默降级为未加密 RFB、未经验证的 Direct 或访问范围更大的路径。云端失效不得妨碍同一工厂内仍合法的 Direct 会话。

## 三、拟新增的产品条款（建议保留第 8 章既有 8.1～8.5）

### 8.6 工厂边缘接入与设备共享

1. 工厂 HyRemoteView 默认不共享任何设备；只有经当地客户管理员明确启用的站点边缘接入才可对外提供受管连接。
2. 共享单位是客户明确登记并验证身份的 **HMI 设备**，而不是 IP 网段、路由表、网卡或工厂 PC 所能访问的任何 TCP 主机/端口。
3. 每台设备必须独立配置可见性、允许的访问人群、期限及停用状态。共享清单不可自动赋予查看、控制或业务数据权限；设备端再次按会话授权。
4. 工厂 HyRemoteView 应显示站点共享开启/关闭状态、连接的 Gateway 身份、当前发布设备数、受管会话数量和最近失败原因。普通远程查看界面不得被复杂的网关运维参数占据。
5. 客户管理员可以禁用整个站点共享，或单独撤销某台 HMI 的共享。撤销后拒绝新建受管会话，关闭不再获准的现有路由并按设备端会话规则释放输入和待发受限画面。
6. Edge 角色不复制 HMI 设备的远控业务：正常转发路径不解码、二次采集或二次编码 HMI 画面，不写入明文屏幕、按键、剪贴板或业务文件内容。
7. 多个站点、多个设备、设备同名、地址变化及站点负责人变更均须按身份区分；不可用内网地址或显示名称作为跨站点唯一安全标识。
8. 明确提示实际可用条件：工厂 PC 运行状态、内网 HMI 可达、Gateway 可信、工厂出站网络、站点授权和 HMI 授权同时满足时，异地访问才有可能成功。任何一项未知不得显示“已可远程控制”。

### 8.7 边缘接入运行与恢复

1. 关闭远程画面窗口不得自动取消客户明确开启的站点共享；关闭/退出 HyRemoteView 主进程、系统用户注销、整机重启、更新和异常崩溃的行为必须在相应平台上**明确且可验证**，不能让用户把“应用在后台”误认为“设备在线”。
2. 同一 HyRemoteView 安装包、配置入口与更新体系承担边缘接入功能，不允许要求客户另装一个独立网关/伴生代理。若采用本产品内部后台/系统服务机制，须由本产品统一启用、停用、升级和卸载，并受到管理员明确授权；在平台不支持某运行方式时如实提示。
3. 出站断开时应如实标明站点离线。恢复后重新校验 Gateway 身份、站点授权和设备清单，不自动恢复已经过期的控制权限，不重放输入或宿主业务操作。
4. 工厂 PC 失效、Gateway 失效、HMI 离线、权限撤销、设备身份改变、版本不兼容、带宽受限，均应具有可区别的用户提示。无法确认业务结果时保持“待确认”。
5. 更新不得破坏本地设备档案和受控共享配置，升级失败应可回退；安全敏感凭据必须受到本地 OS 支持的安全存储保护，不得明文导出。

## 四、拟修订安全/维护条款

### 10.1 设备身份与访问控制（增补）

站点边缘接入引入**站点身份、边缘 HyRemoteView 身份、异地用户身份、HMI 设备身份**四个不同的可信对象，和**站点访问许可、HMI 端会话 ViewGrant/ControlGrant、宿主业务许可**三层不同的授权结果。只有 Gateway 已认证或工厂 PC 已在线，均不能推导设备端已准许查看/控制；未经 HMI 再次批准，转发路径不得代发控制权。

对受管安全连接，应将用户最终信任锚定至目标 HMI，不能仅验证 Gateway 域名便信任任意内网设备。中间节点被攻陷的风险不能通过“云端认证成功”进行消除。

### 10.2 可见范围及隐私遮罩（增补）

站点共享不得使原先不可见的敏感目标突然可见。设备端会话级遮罩、撤权后已排队数据失效及客户端可控旧画面清理，必须跨边缘接入路径一致适用。边缘端与 Gateway 默认不得保存会话原始画面或输入。

### 10.3 审计信息与证据边界（增补）

受管链路须区分记录：站点接入/断开、远程用户准入、设备路由申请/拒绝、设备端授权结果、会话开始/结束和异常原因。仅有 Gateway 转发成功不能作为 HMI 实际执行操作的证据。

### 11.4 优先保障现场应用（增补）

工厂 HyRemoteView 转发受管流量时不得抢占 HMI 本地显示、现场输入及生产业务所需资源；对慢异地用户，设备端应在画面编码和加密之前按其帧调度规则丢弃或合并过期中间画面；工厂 HyRemoteView 和 Gateway 只对透明字节通道实施有界缓冲、背压、超时及必要的路由终止，不得在已加密的 Native/RFB 协议字节流中任意丢弃画面片段。新的边缘转发路径不应导致 HMI 被重复采集或压缩。站点级并发、流量和内存上限应按目标硬件等级定义，并在验收中以真实数据证明。

### 12.2 品牌定制与企业服务（增补）

受管接入和集中运维服务可由客户自托管 Gateway 或接受托管服务提供，必须保留不依赖它们的 Direct 基础能力。品牌定制不能绕过站点共享启用权限或设备端最终授权。客户可以在一个管理界面了解当前站点所共享的 HMI 范围并随时撤销。

## 五、拟新增的完整业务流程

### 13.8 工厂内外协同的远程维护

工厂已有 HMI 1、HMI 2，均运行集成 HyRemote 的 Qt 应用。工厂 PC 仅安装 HyRemoteView，管理员先在局域网验证两台设备身份，通过 Direct 访问确认可用，再启用“工厂边缘接入”并仅将 HMI 1、HMI 2 添加到受管共享清单。工厂 HyRemoteView 主动连入指定 Gateway，不要求 HMI 连接公网，也不配置 HMI 公网入站端口。

异地工程师在自己的 HyRemoteView 选择经授权的站点和 HMI 2，Gateway 核验用户站点许可，并联系工厂 HyRemoteView 建立受控转发。完成对 **HMI 2 本身**的身份核验和查看授权后，才显示获准目标。工程师需要操作时另行申请 ControlGrant，设备端许可前不接收输入。现场人员撤销控制后，传输路径即使仍在线也不能继续发送旧控制权下的新输入。

### 13.9 云端不可用、现场撤销与设备下线

当 Gateway 断开，异地会话显示已失效并停止使用旧控制权；工厂现场人员仍可用同一 HyRemoteView 通过 Direct 访问 HMI。若管理员暂停某台设备共享，已批准的其他设备共享和本地 Direct 不应被误撤销。若工厂 PC 断电或退出，异地必须准确标为不可达，不得显示缓存的“实时在线”；HMI 本地 Qt 业务持续运行。

连接恢复后，用户需重新完成适用的身份/权限核验；断开前未确认的报警确认、参数修改、文件提交等不可自动重发。

## 七、拟新增术语

- **Factory Edge / 工厂边缘接入：** 同一 HyRemoteView 中经管理员启用的受限站点接入能力，只允许路由指定 HMI。
- **Site / 工厂站点：** 管理共享设备范围和异地访问权限的逻辑作用域，不等于某个 IP 网段。
- **Managed Edge：** 经 Gateway 与工厂 HyRemoteView 转发的异地设备访问路径；并不等同于设备端 ControlGrant。
- **Registered HMI：** 经客户验证身份并明确列入站点共享清单的 HMI；登记不自动授予画面查看或输入权限。
- **Route Session / 转发会话：** 受管站点内的通信路由实例，不可直接当作设备会话或自然人授权。
