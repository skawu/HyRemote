# HyRemote 阶段 03｜用户验收、研发依赖、技术决策与实施门禁（D3）

**受控源**：HYR-PD-001/V15、HYR-ARCH-001/V8，产品验收 EDGE-01～EDGE-12，详细设计 D1（模块）、D2（安全与协议）；#831。状态：`DESIGN_CANDIDATE`，无真实端到端产品测试 PASS。

## 1. 测试不以代码或“能连上”为中心

验收的完整用户目标是：客户在工厂 PC 只安装 HyRemoteView，登记 HMI 1、HMI 2，管理员只共享许可设备；异地 PC 运行 HyRemoteView，经过站点许可、路由许可及**真正 HMI 设备端查看和控制授权**访问目标；现场本地业务不受云中断、路由失败或慢客户端影响。所有性能评价需含设备端 Host CPU、帧龄、画面正确性、现场输入响应，以及工厂 PC/Gateway 分别的 CPU/内存/带宽，不以单一静态优化替代用户体验。

### EDGE 12 场景与可检验结果

| 场景 | 必备环境和动作 | 验收断言 | 证据 Owner |
| --- | --- | --- | --- |
| EDGE-01 | 全新工厂 PC 安装 HyRemoteView，HMI 已集成 Framework | 安装/服务/升级清单均无独立 Agent/Connector/Bridge；能配置现场与 Edge 角色 | Windows/Linux 安装+本地 Owner |
| EDGE-02 | 工厂外网断开但 LAN 仍通 | Direct 浏览目标/获准输入正常，HMI 原 Qt 业务继续 | 真实本地设备+Viewer |
| EDGE-03 | 新安装初始配置不启用站点共享 | Gateway 无任何可申请路由，不能默认曝光 HMI | API/黑盒安全 |
| EDGE-04 | 仅分享 HMI1，存在 HMI2、数据库、打印机 | 异地只能到 HMI1，任意端口、内网主机/IP、错误 ID 被拒绝 | 安全负向 |
| EDGE-05 | 两工厂同名设备、更换注册设备 IP/证书 | 身份可信锚绑定，不串站点，设备身份不符时拒绝而非静默转向 | 身份/重绑定 |
| EDGE-06 | 用户有 SiteAccess、Route Admission，但 HMI 拒绝 ViewGrant | 不能看到受限真实画面/目标，UI准确标明设备端拒绝 | 客户端+HMI |
| EDGE-07 | 只读、申请 ControlGrant，之后现场撤权 | 仅获准后才输入；撤权后无新输入、已按键安全释放 | HMI 输入+Viewer |
| EDGE-08 | 敏感画面/水印与 Grant 变化 | HMI 先遮罩，途中不泄露；撤权后缓存失效，不能靠 View 叠遮罩 | 隐私/字节路径 |
| EDGE-09 | Gateway、Edge、HMI、Viewer 分别掉线 | 路由断开、错误可区分、无自动降级/旧命令重放；Direct独立 | 故障注入 |
| EDGE-10 | View 窗口关闭、程序退出、用户注销、PC 重启/升级 | 每平台运行方式真实、未支持时提示，不能“假在线” | 实机安装与 OS |
| EDGE-11 | 同一 Edge 多 HMI、多 Viewer、慢网络和限流 | 没有二次抓图/重编码，内存队列有界；HMI现场响应有真实量化结果 | 性能与长稳 |
| EDGE-12 | Gateway 中断/企业服务过期/设备许可证仍有效 | 基础 Direct 不受影响，无不当云依赖或逆向授权升级 | 授权与离线 |

除 EDGE-01 的同安装证明外，每个测试都必须报告 **exact SOURCE_SHA + 二进制/安装清单 + OS/Qt Kit/设备类型 + Gateway 版本 + 实际 Viewer + 试验流量和失败证据**。缺哪一项就相应标 `NOT_RUN` / `LIMITED`，不能填 PASS。Native 未发布则其受管资格 `NOT_AVAILABLE`；不能由 RFB 旧测试填上。

## 2. 真实用户旅程的测试分层

- **层 A｜快速逻辑测试（无需设备）：** 身份 ID 与设备名/IP 不混淆、共享默认关闭、RouteTicket 过期/重放/撤销/跨租户/错误 audience 拒绝、慢端背压和 Queue 上限、进程退出幂等 Close、配置迁移、安全存储接口 mock。
- **层 B｜组件集成（可本地模拟）：** Gateway↔Edge 模拟授权与通道配对，模拟 HMI 设备会话拒绝、端到端字节原样完整传输、DNS 重绑定拒绝、断线重认证、Gateway 单节点重启。
- **层 C｜有真实 Qt 设备/Viewer 的产品资格：** Windows 工厂 PC + HMI1/2 + 异地 PC + 单节点 Gateway，LAN/Internet 路径切换、真实像素、键盘/鼠标/IME、DPI/缩放、嵌入式 Qt 场景与撤权后的 held-input 清理。
- **层 D｜运营可靠性：** 凭据轮换/吊销、升级回滚、受管 Edge 无人值守注销/重启（若要产品承诺）、自托管安装恢复、并发资源与 WAN 弱网。EGLFS/RK3588 等设备按准确平台资格；现有 #789 性能 P1 不被此阶段自动关闭。

**测试经济性**：只在本模块合同变化时运行相应快速测试，安全硬门禁必须有负向证明；真正产品里程碑才作精确 SHA 全套验收。不得因为只是设计 PR 而调用真实 Qt G6 或让 Human 监控半小时矩阵；也不得把模拟测试成功当成实际设备通过。

## 3. 故障矩阵与用户状态

| 故障 | Edge/Gateway 动作 | 设备端动作 | 用户可见 |
| --- | --- | --- | --- |
| Gateway 消失 | 站点状态 DEGRADED、结束依赖失效连接、有界重试 | 无影响 Direct、本地业务正常 | 异地受管不可达，工厂 Direct 正常 |
| 工厂 Edge 退出/网络失效 | 不再接受路由，关闭已建立 Route/通知离线 | 设备清理对应断开会话和按下输入 | 明确站点不可达，无旧在线 |
| HMI 断线或身份替换 | 对应 HMI 路线关闭，不跳转同 IP 其他服务 | HMI 恢复后也需重新认证/授权 | 指定设备不可用或身份已变化 |
| Gateway 许可撤销 | 拒新 Route、终止当前受影响 Route | 对相关连接按断开规则回收 | 站点/分享权限已失效 |
| HMI ControlGrant 撤销 | Byte route 可在合法只读条件下保持 | 立即阻止新控制输入与释放 held-input | 查看仍获准则只读，否则关闭 |
| 异地慢 Viewer | Queue 背压、上限超时 Route CLOSE | 设备协议可在**编码前**合帧、不得被 Edge 丢密文字节 | 连接质量差/超限终止 |
| 系统注销/重启 | 按已签收的运行模式执行停机/恢复，需重认证 | 本地运行不因云断网中止 | 如实标在线或不可用 |
| 证书轮换/吊销 | 版本化信任与 fail closed，不静默转 plain | O↔H 设备证书再核验 | 需要重新建立可信连接 |

所有业务写入、报警确认、参数调整之类具有副作用的操作，断线恢复**不得自动重发未确认指令**；只能让宿主提供明确的幂等/查询业务接口时依业务级证据处理，不由 Edge 猜测执行结果。

## 4. 设计任务先后关系及唯一工程路径

```text
V15/V8（APPROVED）
  ↓
D1：View内置 Edge 模块/身份模型 ─┐
D2：Gateway协议/威胁与E2E安全 ──┼──> D4：全部关键技术契约决策/资源预算冻结
D3：验收标准/平台支持边界 ─────┘                  ↓
                                       有界原型证明（只验证尚无法由文档确定的风险）
                                                ↓
                                     分模块详细设计签收/实施分期
                                                ↓
                                         正式授权后开始代码
                                                ↓
                                      安全负向 + 真机产品验收
```

**跨仓库真实情况**：HyRemoteView 当前公开仓库仅有早期 PoC/基础边界代码，不能按“改一个 Viewer 模块”估算完整产品。Gateway 控制面/身份/转发、View 客户端 GUI/后台、设备端 Native TLS/真实身份、整合安装与升级均需各自估算。现有 HyRemote Framework 设备端 Native/RFB 架构设计是需求基线，不是已实现证明。

## 5. 技术决策清单（不应让 Human 日常介入）

| TD-EDGE-05 | 后台运行 | 有人值守先可用、无人值守另行同产品 OS 机制资格 | Windows 注销/重启/升级真实测试及最小权限审查 |
